# Cypher XP (v1.13.0 — Foundry v14+)

GM-approved Development Track advancement module for the Cypher System, with
Cypher Taskbar and Cypher GM Taskbar integration.

## v1.13.0 — Sleek Aetherium Design Overhaul

The complete visual system has been rebuilt while retaining all functionality:

- **Premium windows:** glass-and-metal window chrome, layered dark surfaces,
  gold accent lines, stronger depth, custom shadows, and refined native
  Foundry header controls.
- **Modern layouts:** flex-bounded content, improved visual hierarchy,
  responsive stat-card grids, compact premium tabs, refined lists and tables.
- **High-quality interactions:** hover lift, colored glow, focus states,
  smooth transitions, premium button treatments, and clearer states for
  requests and tier-ready actors.
- **Charts:** redesigned cards, SVG charts, legends, donut displays, grouped
  party comparisons, and high-contrast axes/labels.
- **Player vs GM identity:** player launcher has a teal accent; GM launcher
  retains the gold accent. Flyouts, badges, and fallback positions remain
  distinct and readable.
- **Rules panel:** retains the parchment layout from the original uploaded
  document, now visually integrated with the premium module window frame.
- **Responsive design:** key grids collapse cleanly for narrower windows.

No rules, data paths, transaction logic, chart tracking, or integrations were
removed or altered in this visual release.

## Install

Extract the ZIP into `FoundryVTT/Data/modules/` so the folder is
`Data/modules/cypher-xp/` (no version suffix), restart Foundry, enable
"Cypher XP" in Manage Modules, and reload the world.
